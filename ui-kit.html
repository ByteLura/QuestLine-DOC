The UI Kit

Three uGUI components, built from code at runtime — no prefabs to wire, no canvas to set up by hand. QuestUiFactory.BuildAll creates the set (canvas, HUD, log panel, toast queue) bound-ready for a tracker.

  • Tracker HUD. The active quest with live objective lines: each line carries the current count and the target; a completed objective reads complete. Formatter-driven, so the text rules (including hidden-achievement masking) are unit-tested, not eyeballed.
  • Quest log. Quests listed in state sections — active, available, completed, failed — with achievements below; hidden achievements read masked until they unlock.
  • Toast queue. Completion, reward and achievement toasts surface in arrival order, one at a time (3.5 s by default; the timing is a public field), and the queue drains to empty.

The kit uses uGUI's built-in Text — no TextMeshPro, no added package dependency. Treat it as a working starting point: restyle the factories, or bind your own UI to the same tracker events and drop the kit entirely.
