Guides

Achievements

Achievements live in the same catalog as quests and ride the same tracker, so an unlock is one event in one system — not a second progression engine to keep in sync.

Two shapes

  • Quest-linked. Set LinkedQuestId on the achievement definition. When that quest completes, the achievement unlocks — once. A second unlock attempt is a no-op: no event, no second adapter call.
  • Progress. Set a progress target id and a required count. Every matching progress report accrues; the achievement unlocks exactly when the count reaches the target — not before, not twice.

Hidden achievements

Mark a definition Hidden and the quest log masks it — the line reads “Hidden achievement” — until it unlocks. From the unlock on, its real title shows.

Where unlocks go

The tracker's achievement component raises the unlock; the sync service routes it to every registered platform adapter (see Platform Adapters), and the included toast queue shows it to the player. Progress reports route the same way, carrying the platform id, the current count and the target.
