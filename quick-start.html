Getting Started

Quick Start

From import to a quest completing itself on screen, in about ten minutes. Every name below is the name you will see in the editor.

Requirement: the UI kit and the demo build their screens with Unity's UGUI package (com.unity.ugui). It is included in the standard Unity project templates; if your project was created from a minimal template without it, add UGUI from the Package Manager before importing — the package itself declares no dependencies.

1. Open the home window

Tools > ByteLura > QuestLine Pro. The window opens on a welcome header: what the package does, the six things you will use most, and your catalog once one exists.

2. Create the starter content

Click Create Starter Content. It creates, under Assets/QuestLine Pro/:

  • a catalog asset, selected for you;
  • First Steps — a three-node quest (Start → gather 3 training tokens → End) with an experience reward on the gather node;
  • The Branching Path — a quest locked behind First Steps, whose gate node waits for a conversation flag before the bell objective opens;
  • two achievements: First Steps Complete and Token Collector.

Running it again changes nothing — it reports that the starter content already exists and leaves your edits alone.

3. Look at the quest tree

In the home window, click Open in Tree Editor on First Steps. You are looking at the quest as a graph. Click the objective node: the panel on the right shows its objective (Collect, target training_token, 3 required) and its reward. Drag a node — its position saves into the quest asset. Click Validate: the graph is clean.

4. Run the demo end to end

Click Open the Ember Road Demo and press Play.

  • First Embers is already active in the tracker HUD. The demo starts each quest the moment it unlocks.
  • Click Collect Ember Shard three times. The objective counts up; the quest completes; toasts report the completion, the reward, and the First Embers Complete achievement.
  • The Gatekeeper's Price starts. Pull the Gate Lever does nothing yet — click Speak to the Gatekeeper first, then pull the lever to finish and receive the gate key.
  • Two Roads starts and its branch routes immediately: reputation below 5 sends you down the toll road. Finish either road; both rejoin at a reward node, and Road Walker unlocks.

5. Your first quest of your own

  1. Duplicate the First Steps quest asset and add it to your catalog.
  2. Open it in the Tree Editor. Add an Objective node, connect Start → your node → End, and set its objective: a kind, the target id your game will report, and a required count.
  3. In your game code, report the event where it happens:
QuestLineRuntime.Instance.Tracker.AddProgress("training_token");

That call is the whole integration surface for progress. The full surface — starting and failing quests, flags, stats, snapshots — is in the API Summary.
